# v0.1.1-handle-attachment-axis

发布日期：2026-10-30。基于 `v0.1.0-auto-semantics-pose`（`d0baa9b`），继续使用分支 `research/auto-semantics-pose-20261030`。

本补丁修复可转动提手的轴定位：当完整提手的主体接触簇不足、退回两根支杆推断时，旧版把两根支杆的几何中心连线当作转轴，可能让提手绕支杆中段转动。新版使用靠近主体的连接端推断轴；固定在门/抽屉上的拉手仍随父部件运动。

## 规则与证据

1. 保留原先“两处分离主体接触簇”的优先路径。
2. 后备路径仍要求两根足够长、细且横向分离的支杆。分别沿每根支杆的PCA主方向，以3%/97%分位的端部点集计算端部中位位置。
3. 选择更靠近生成主体的端部。要求该端部距离不超过原生生成物体对角线的8%，且另一端至少远 `max(1%对角线, 25%当前距离)`；否则拒绝该支杆的连接证据。
4. 两个连接端用于拟合轴方向，沿用12°以内的规范方向吸附。轴位置按 `1/(端部到主体距离 + 0.5%对角线)^2` 归一化加权，避免截断支杆把可靠连接处拖向缺口中间。方向吸附及生成几何误差意味着轴未必精确经过两个候选端点。
5. 证据不足时保留原生关节，输出 `handle_native_unresolved`，不再使用支杆中心生成后备轴。连接端间隙超过3.5%对角线时标记 `approximate_body_gap`。

这些距离是原生生成几何上的规则阈值，不是GT误差阈值，也不证明实际机械连接。审计输出保留端点、端点到主体距离、权重、支杆中心和拒绝原因。支杆中心只参与配对及诊断，不作为连接点。轴线上的原点可取任意位置，不能将“沿轴移动原点”误称为改变轴线。

代码改动：`semantic_motion_rules.py` 的 `paired_handle_component_axis` 新增 `static_vertices`；`auto_component_axis_prior.py` 传入主体几何，并消费 `attachment_points`。没有主体证据的直接调用会抛出 `ValueError`，调用方需提供主体或处理未解决结果。

## 验证范围与限制

- 45项单元测试通过，覆盖下端/上端连接、主体远离、端点歧义、截断支杆、单根支杆不足、禁止中点回退，以及原门/抽屉/把手规则和FK。
- 100481左右提手均实际走过此新后备路径。原mask、原生Mesh/GS、组件归属、非提手关节和提手行程幅度保持不变；轴候选封存后，另从原生几何基于新轴重新拟合240步，生成 **GT → Origin → 修复后的VLM轴 → 修复轴＋几何优化** 视频。84帧全部解码。
- 后侧生成支杆存在缺失，新轴是近似连接证据估计。本轮未新增GT轴准确率或表面CD结论，也未按GT选择规则或checkpoint。
- 训练图IoU从旧轴几何版95.52%变为95.42%，部件mIoU从71.45%变为69.56%；不能将这次轴规则修复描述为所有几何指标改善。
- 此前10-case批量结果属于v0.1.0规则，未按本补丁重跑。其轴正确数8/24→15/24不是本次新规则的成绩。
- 本补丁不包含后续行程优化代码，没有修改几何优化损失、观测角度搜索或原mask边界。研究缓存、相机与路径依赖沿用[基础版本说明](v0.1.0-auto-semantics-pose.md)。

本地证据目录（数据、视频和此次诊断/视频包装脚本不随本补丁发布）：

- `repro/outputs/handle_attachment_axis_20261030_v1`：连接端、旧/新轴对比图及核验。
- `repro/outputs/handle_attachment_four_versions_20261030_v1`：新轴上的全新几何拟合、四列视频及核验。

## 使用

在既有输入、VLM语义及RGB/轮廓配准缓存齐全后，通过已发布入口生成新目录的规则轴；不会自动重新运行VLM或几何优化，也不要覆盖旧结果：

```bash
PYTHONDONTWRITEBYTECODE=1 OPENCV_IO_ENABLE_OPENEXR=1 OMP_NUM_THREADS=4 \
/root/autodl-tmp/conda_envs/pact/bin/python repro/tools/auto_component_axis_prior.py \
  --auto-root repro/outputs/auto_semantic_pulls_20261029_v1 \
  --registration-root repro/outputs/general_semantic_priors_20261029_v2 \
  --output repro/outputs/handle_axes_REPLAY \
  --case 100481
```

测试：

```bash
PYTHONPATH=repro/tools PYTHONDONTWRITEBYTECODE=1 \
/root/autodl-tmp/conda_envs/pact/bin/python -m unittest \
  test_auto_semantic_axes test_semantic_motion_rules test_door_pull_priority \
  test_vlm_component_geometry test_observed_drawer_pose
```
