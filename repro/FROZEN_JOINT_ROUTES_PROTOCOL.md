# 冻结部件的两条实验路线

用户明确要求冻结 PAct 生成的部件，只研究轴的位置、方向和运动起止值，并授权两条路线都试。本轮不使用可变形的旧 checkpoint，不增加 RGB 重建目标，不优化几何、外观、类型或层级。此文件是事先配置，不能当作已完成结果。

## 共用输入与分组

先按固定 seed42、25+25采样步、CFG7、最后20步平均特征的原版设置，重新生成6个对象，并在同一次推理缓存原版关节 MLP 的输入。输入为既有 RGB 与 oracle 2D masks。特征/部件的同次生成关联必须通过核验；旧资产保留，不替换。

四个关节头训练对象固定为10489、31249、45503、9016；两个测试对象为8961、45194。后处理路线仅在这两个测试对象执行。头部训练不读取测试 GT；局部对象划分不重叠，不宣称排除了与预训练集的重叠，也不是此前未看过GT的盲测。

此前一次仅缓存特征、与旧推理结果比较的尝试未满足预设回放差异阈值，失败日志保留。故不混用旧几何与重新生成的特征，改为同次推理保存全部输入和部件，并且检查缓存 raw 值与该次官方导出的 joint trace 完全相同。跨次推理差异记录，不伪称固定seed即可逐位复现。

## direct：冻结导出部件，直接优化参数

- A：原始参数的归一化二次先验，固定200步；初始化处是驻点，预期参数不动。明确承认它是新增后处理对照，不叫原版训练。
- B：同一先验、初始化、自由度与预算，额外加入运动 Gaussian-overlap proxy / 初始 proxy。先验权重0.05，碰撞权重1。
- 仅方向切平面2参数、转轴有效pivot平面2参数和每关节起点/终点2参数可更新。方向最大偏转5°、pivot最大位移为初始资产对角线5%。端点相对原值最多变化15°或0.1资产对角线；所有界限A/B一致。
- 起止值不设GT目标；可训练行程可能缩短、反向甚至接近0，必须如实报告。共同原始范围上的碰撞评价用于区分轴改善与行程缩短。不能据此证明已恢复真实机械极限。

## head：保留原文关节监督项的小规模冻结网络微调

- 使用官方 `ArticulationRegressionHead.art_out_layers` 三层输出MLP及已验证的官方权重，不另设计预测网络。输入投影、生成骨干、latent与decoder冻结，不通过重生成改变几何。
- A：原版 masked articulation MSE；B：同一项加0.02倍归一化运动碰撞代理。两组 AdamW(lr=1e-4,weight_decay=0)，相同追加200步、新建optimizer。不是恢复作者optimizer，也不是完整flow-matching续训。
- 固定缓存4个单推理时刻6/12/18/25的池化特征，轮流训练；最后使用原版最后20步平均特征评价。特征来自推理分布，不能说成原版随机GT latent加噪的训练数据。
- 使用官方24维编码函数生成训练对象目标。GT方向/pivot用固定坐标旋转与GT静态AABB相似变换映射到生成坐标；GT范围转为零起点的signed span。GT进入训练是明确的监督设置。
- 原版validity mask额外限制到用户要求的连续通道6:18；类型、语义、层级保持原预测。错误类型不修正、不隐去，类型不匹配的训练部件不监督其连续参数。
- 原版输出把起点固定为0；本轮保留这一约定，只更新终点，不新加起点输出头。若后续要头部同时预测两个自由端点，应另列表示扩展实验。
- 保留官方原版编码/解码：encoder的range连续重复与decoder的交错平均并非完全互逆，本轮不修改它们。
- 碰撞项用连续raw方向与pivot，允许实际反向传播；官方导出中的坐标轴吸附及bbox投影另用原函数评价。同时报告raw与official两套结果，禁止用straight-through把原版硬吸附假装成可微。它们的R0基线分开保留。

## 刚体和梯度门槛

局部Gaussian中心、椭球、opacity、颜色与完整Mesh顶点/拓扑恒定；仅刚体FK作用于运动中的部件。原资产SHA封存，并验证运动前后的内部成对距离不变。Torch FK须与原版参考变换一致，Gaussian proxy须与既有实现一致。

真实数据上检查：direct方向/pivot/两个端点的碰撞梯度，head官方MSE与运动项到官方MLP的梯度，以及连续方向/pivot/range输出梯度。检查原版MLP输出复现及原版后处理复现，不通过则停止。A/B各先做30步smoke；另做零权重一致性和真实中断10步→恢复至30步对照。门槛通过后才启动200步正式实验。

运动训练为每条21状态、逐关节独立与同步路径，确定性循环每步3状态。每部件512个固定源Gaussian，对全部opacity≥0.05目标查最近邻，每步更新对应。模型、Loss、SHA、Adam与日志每10步保存，严格匹配后恢复，不覆盖已有实验。

## 评价与交付

固定最终步，无GT最优checkpoint选择。封存后才读取测试GT。使用同一新原版baseline的静态几何相似变换评价所有候选，不能逐候选再拟合。

逐部件报告方向误差、pivot到GT轴线的垂距、实际原点位移与方向改变、起止值与实际行程；移动关节pivot为N/A，错误类型保留。绝对端点GT误差在rest gauge未可靠对齐时为unavailable，不用signed span冒充绝对端点误差。

评价每条路径41状态、与训练源不重叠的最多2048中心；同时给出候选自身范围和共同原始范围的碰撞曲线、最近中心距离/1-sigma间隙。完整原始Mesh只作刚体运动预览，无变形、修复或简化。Gaussian代理与Mesh实体碰撞区分；未建立合法封闭实体前体积和穿透深度为unavailable。
