# 稀疏双状态下的部件—关节结构候选协议 v1（建议稿）

## 研究问题

> 给定同一物体在两个不同运动状态下的 RGB 图像，在缺少连续运动轨迹和人工关节标注的条件下，如何利用生成式形状先验恢复同时解释两个观测的部件几何与运动结构？

初版限定：同一或近似相同视角；两状态确实拍到机械极限时，才讨论完整行程；否则只恢复两个观测之间的运动幅度。

## 统一基线

| 项 | 规定 |
|---|---|
| 初始几何 | 同一份 PAct Origin；不因 case 重采样 |
| 输入观测 | 两个运动极值帧的 RGB 与实例 mask；同一/近似视角 |
| 语义 | 本地 VLM 输出类别、运动角色、连接证据与置信度；不输出数值轴 |
| 优化器 | 所有候选共用同一损失、步数、学习率与早停规则 |
| 历史回退 | 禁止；失败候选保留并报告 |
| GT 使用 | 只在全部候选封存后评价；不参与候选生成、选择或调参 |

## 结构候选

对每个独立可动物理实例，生成少量候选而不是直接锁定一个：

- 运动类型：`revolute` / `prismatic`（必要时保留 `unknown`）；
- 连接边：门的左/右/上/下铰链；抽屉的抽拉方向；
- 父部件：柜体或相邻部件；
- 每个候选带先验来源与置信度；**同类先验不等于共享运动参数**；
- 两个门、两个提手保持独立实例与独立关节，即使共享类别或形状参数。

候选验证：每个候选用同一优化器同时解释两张输入图；先固定/受限几何验证运动，再逐步放开几何自由度。输出保留无法消除的结构歧义，不强制给单一轴。

## 四组比较

| 组 | 回答的问题 |
|---|---|
| 单状态 + 硬语义规则 | 当前路线的基础能力 |
| 双状态 + 硬语义规则 | 单纯增加观测的收益（已有基线） |
| 双状态 + 结构候选选择 | 候选推断是否有效 |
| 双状态 + 候选选择 + 受限几何修复 | 是否减少几何与运动互相补偿 |

## 指标

- 主指标：CD（Chamfer Distance），报告十例均值与逐例值；
- 逐部件 CD、遗漏部件数；
- 关节类型准确率、旋转轴方向误差、轴线位置误差；
- 未参与优化的中间帧运动一致性；
- 自动 mask 与理想 mask 分开实验，避免把分割错误与后续推断错误混在一起。

## 失效判据

若在候选封存后，结构候选选择相对“双状态 + 硬规则”没有改善 CD 与关节指标，或改善只出现在使用了 GT 信息的环节，则不成立；不得用增加优化预算或换一张图解释收益。

## 输入边界

当前先导实验仍使用数据集 GT 投影得到的实例 mask 与已确定的关闭参考帧；因此只能称为“带实例 mask 的双状态重建”，不能称为“仅两张 RGB 的全自动重建”。自动分割与跨帧身份跟踪需单独量化为后续项。
