# 研究问题校正：运动碰撞 Loss 是否改善重建

状态：已实现第一轮场景细化对照，先做梯度与 smoke 验证再正式运行；完成状态与实测结果另见本轮结果报告。此前固定几何的轴优化、原版场景筛选及其所有正负结果保持原样。

## 要回答的问题

在相同数据、初始化、可训练参数、优化预算与评价协议下，加入整个运动过程的碰撞 Loss，相比不加入它，是否改善重建的几何、外观、关节参数与运动合理性？不预设改善一定发生，也不以碰撞代理下降代替重建改善。

原版 PAct 输出 R0 留作参考。决定性对照是两组均执行同一重建/细化流程：

- A：基础重建目标 L_base，collision 权重为 0。
- B：同一 L_base，加 lambda * L_collision_motion。

A/B 必须同时开放相同的几何与关节参数；若只开放轴，只能回答轴和运动装配是否改善，不能回答静态几何是否改善。每场景细化与 PAct 网络微调是不同研究设置，需在正式配置中明确，不能把后处理称为原版 PAct 训练，也不能将原始输出与额外优化的结果之间所有差异归因于 collision Loss。

## 对照约束

两组共享输入、mask 来源、模型权重、随机种子、初始 Gaussian、关节初始化、相机/尺度处理、训练图像、留出图像、优化器、步数、正则、可训练参数、点采样、运动范围及最终步 checkpoint 规则。仅 collision 权重不同。不用最终 GT 分数选 seed、lambda、checkpoint 或隐藏失败案例。

碰撞 Loss 在运动变换后的部件上计算，不只计算起始姿态。逐关节至少采样 21 状态，其余关节固定，并单独记录同步轨迹；较多关节的组合覆盖须明确说明。训练采样之外另用插值状态评估。两组运动范围相同且不能通过缩小范围降低碰撞；人为指定范围时单列假设实验，GT 范围若进入优化须明确标为 GT-assisted。

GT 轴/pivot 不进入每场景无 GT 细化的 Loss 或 checkpoint 选择。输入采用 GT 投影 mask 时沿用明确的 oracle-segmentation 披露。若改走原版监督式网络训练，GT geometry latent 和 articulation target 本身是训练监督，必须另列训练/验证对象划分，不能再声称全部 GT 仅用于评估。

## 主评价

同时报告 A、B 与 B-A：留出图像 PSNR/SSIM/LPIPS，固定/活动/整体几何 Chamfer，类型与有效 Axis/Pivot 误差，运动过程重叠的均值/最坏状态/曲线，以及几何完整性、间隙、漂移、尺度/opacity 退化和行程是否改变。GT 几何评价使用共同全局对齐，不能对每个结果的活动部件独立配准后掩盖装配误差；shape-only 诊断单列。

重叠下降而 Chamfer、图像或轴误差恶化，应报告为代价或失败，不称为重建改善。Gaussian proxy、表面交线、实体体积与穿透深度区分。只有 Mesh 满足相应实体计算前提时才报告真实体积，否则 unavailable。

不要求预先找到“形状完美但轴错”的案例才能开展 A/B。可以在类型/数据可用的不同难度案例上检验收益，保留全部预先选定案例。8961 目前只是一项新的原版 baseline；其不足 1° 的预测范围不支持将原生范围实验解释为完整开合。

## 运行前门槛与当前事实

1. 当前已运行的是预训练推理和冻结 Mesh/Gaussian 的轴后处理。`refine_collision_axes.py` 的 `geometry_frozen=True`，所以已有几何文件不变是设计结果，不能据此证明该 Loss 对可训练几何无效。
2. 当前 checkout 的官方 Stage 2 trainer 是 flow matching MSE + articulation MSE；未接入运动碰撞重建目标。离线导出的 PLY/object.json 不构成连回网络的可微训练图。
3. 现有 VideoArtGS 图像、相机、mask 与 GT 可用于建立每场景数据接口；本轮有限深度搜索未发现现成的 PAct `dataset_index.jsonl`/`data_split.json`，不能宣称完整网络训练数据已就绪。
4. 正式运行前需完成基础重建项、相机/rest pose/运动范围来源、可训练表示及评价划分的具体配置。对同一真实场景先测试基础目标与运动项的梯度；lambda=0 两组应具有相同更新；再做几十步 GPU smoke，检查显存、NaN、几何退化、checkpoint/恢复和输出。
5. 上述门槛通过后才用 tmux 执行等预算 A/B，保留 R0，固定最终步选择，逐场景执行。当前没有这些 A/B 实测结果，不填写预计收益或假设的提升百分比。

## 第一轮固定配置（正式 A/B 运行之前声明）

三组成对实验，共六次优化：8961 原生范围、8961 按原预测转动符号规定 90° 的假设范围、45194 原生范围。保留 45194 的错误类型，不用 GT 修正。90° 不是从该场景 GT limits 拷贝，也不是原版预测范围，不保证对应合法机械极限，只是单列的大幅运动诊断。

采用现有相机中 state=0 的六个训练视角 0/25/50/75/100/125，六个留出视角 12/37/62/87/112/137，分辨率192。原始 PAct 只输入首帧；这里细化额外使用多视角 RGB 与 GT 投影 oracle 2D mask，所以是多视角后处理，不代表原版单视图网络的泛化提升。训练优化程序不读取源数据目录/GT Mesh 或关节文件；只读取预先打包的 RGB、2D 标签和相机。

共同初始化阶段固定几何和轴，利用训练图像拟合全局 uniform scale/translation 与观察姿态的各关节 q，共200步。固定坐标旋转来自已有导出约定，不用GT几何拟合。观察姿态 q 可超出网络预测行程以适配输入打开姿态，但正式碰撞范围始终按各实验明确的 native 或90°设置；两者不可混称。共同初始化封存后，A/B 均冻结 similarity、相机与观察姿态 q，只开放相同的几何场、轴方向和 pivot。

每部件 4x4x4 三线性向量场，共同变形 Gaussian 中心与 Mesh 顶点，逐控制点位移不超过初始资产对角线3%。Gaussian opacity、尺度、旋转在 canonical frame 中及颜色固定；关节转动时协方差随刚体旋转。局部变形没有额外优化 Gaussian 椭球形状，不引入增密/删点。Mesh 三角拓扑不变。方向范围5°，pivot位移上限10%资产对角线，均相对原始轴；相同限制用于 A/B。

正式每组200步：RGB 前景加权 L1 + 2倍 semantic-palette MSE + .001归一化几何幅度 + .001几何平滑 + .001归一化轴参数正则。B额外加 .02 × motion Gaussian proxy / 共同初始化 proxy；A权重0。每部件固定1024源中心，最近邻目标包含全部 opacity≥.05 Gaussian，每步刷新对应并允许对双方几何求导。21点/路径（每关节独立运动及同步路径）按预定义顺序循环，每步3状态；200步覆盖全部预定义状态。最终评价使用41点/路径与独立源采样。A也计算相同运动项但权重0，以保持同一代码/样本路径。无 lambda 搜索、无 GT checkpoint 选择。

共同初始化与正式训练先保存渲染预览；真实数据的图像/运动项几何和关节梯度检查、30步 smoke、lambda=0 两臂更新一致性通过后再跑正式六组。优化保存10步 checkpoint、Adam、历史与来源SHA，支持严格协议匹配的 resume。开发 smoke 与正式结果隔离。
