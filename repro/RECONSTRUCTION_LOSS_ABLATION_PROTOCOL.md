# 研究问题校正：运动碰撞 Loss 是否改善重建

状态：对照协议与代码可行性检查；尚未实现或运行下述重建 A/B。此前固定几何的轴优化、原版场景筛选及其所有正负结果保持原样。

## 要回答的问题

在相同数据、初始化、可训练参数、优化预算与评价协议下，加入整个运动过程的碰撞 Loss，相比不加入它，是否改善重建的几何、外观、关节参数与运动合理性？不预设改善一定发生，也不以碰撞代理下降代替重建改善。

原版 PAct 输出 R0 留作参考。决定性对照是两组均执行同一重建/细化流程：

- A：基础重建目标 L_base，collision 权重为 0。
- B：同一 L_base，加 lambda * L_collision_motion。

A/B 必须同时开放相同的几何与关节参数；若只开放轴，只能回答轴和运动装配是否改善，不能回答静态几何是否改善。每场景细化与 PAct 网络微调是不同研究设置，需在正式配置中明确，不能把后处理称为原版 PAct 训练，也不能将原始输出与额外优化的结果之间所有差异归因于 collision Loss。

## 对照约束

两组共享输入、mask 来源、模型权重、随机种子、初始 Gaussian、关节初始化、相机/尺度处理、训练图像、留出图像、优化器、步数、正则、可训练参数、点采样、运动范围及最终步 checkpoint 规则。仅 collision 权重不同。不用最终 GT 分数选 seed、lambda、checkpoint 或隐藏失败案例。

碰撞 Loss 在运动变换后的部件上计算，不只计算起始姿态。逐关节至少采样 21 状态，其余关节固定，并单独记录同步轨迹；较多关节的组合覆盖须明确说明。训练采样之外另用插值状态评估。两组运动范围相同且不能通过缩小范围降低碰撞；人为指定范围时单列假设实验，GT 范围若进入优化须明确标为 GT-assisted。

GT 轴/pivot 不进入每场景无 GT 细化的 Loss 或 checkpoint 选择。输入采用 GT 投影 mask 时沿用明确的 oracle-segmentation 披露。若改走原版监督式网络训练，GT geometry latent 和 articulation target 本身是训练监督，必须另列训练/验证对象划分，不能再声称全部 GT 仅用于评估。

## 主评价

同时报告 A、B 与 B-A：留出图像 PSNR/SSIM/LPIPS，固定/活动/整体几何 Chamfer，类型与有效 Axis/Pivot 误差，运动过程重叠的均值/最坏状态/曲线，以及几何完整性、间隙、漂移、尺度/opacity 退化和行程是否改变。GT 几何评价使用共同全局对齐，不能对每个结果的活动部件独立配准后掩盖装配误差；shape-only 诊断单列。

重叠下降而 Chamfer、图像或轴误差恶化，应报告为代价或失败，不称为重建改善。Gaussian proxy、表面交线、实体体积与穿透深度区分。只有 Mesh 满足相应实体计算前提时才报告真实体积，否则 unavailable。

不要求预先找到“形状完美但轴错”的案例才能开展 A/B。可以在类型/数据可用的不同难度案例上检验收益，保留全部预先选定案例。8961 目前只是一项新的原版 baseline；其不足 1° 的预测范围不支持将原生范围实验解释为完整开合。
